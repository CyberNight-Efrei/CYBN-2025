En utilisant [ce sketch Arduino](https://github.com/gillham/logic_analyzer/blob/master/examples/logic_analyzer_sigrok/logic_analyzer_sigrok.ino), on peut connecter l'Arduino à [PulseView](https://sigrok.org/wiki/PulseView) afin de mieux analyser le signal.

Avec le titre du challenge et les 3 premières séquences, on se rend compte qu'on à affaire à du morse.

On peut ajouter un décodeur dans PulseView qui décode automatiquement le flag, plus qu'à le rentrer.
